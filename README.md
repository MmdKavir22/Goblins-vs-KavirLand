# Goblins vs KavirLand

A native Android mobile FPS prototype built in Java with no external game engine.

## Current version
**0.0.3 beta**

### 0.0.3 highlights
- Real 3D perspective rendering with OpenGL ES 2.0
- Yaw + pitch FPS camera
- Lit 3D terrain and environmental props
- 3D goblin enemies with multiple classes
- 3D weapon, recoil, muzzle flash and particles
- Mobile joystick + touch look + FIRE controls
- Polished Android HUD overlay
- Wave survival, XP, levels, gold and death/restart loop

The project is intentionally dependency-light so GitHub Actions can build the Debug APK directly.
