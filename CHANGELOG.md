# Changelog

## 0.0.3 - True 3D FPS
- Replaced the 2D Canvas battlefield with a real OpenGL ES 2.0 perspective renderer.
- Added yaw + pitch FPS camera, depth, lighting, culling and perspective projection.
- Added lit 3D goblins with distinct Normal, Runner and Elite silhouettes.
- Added 3D weapon model, recoil and muzzle flash.
- Added 3D particles, terrain, rocks, trees and environmental depth.
- Added mobile FPS controls with separate movement joystick and look/fire zones.
- Added polished Android HUD overlay while keeping rendering dependency-free.
- Added configurable sensitivity and wave flow.

## 0.0.2
- Expanded waves, enemy types, HUD, settings and procedural visuals.

## 0.0.1
- First playable beta with touch movement, aiming and goblin waves.
