# Goblins vs KavirLand

A mobile Android prototype inspired by fast fantasy horde-survival FPS gameplay.

## Prototype
- First-person-style raycast arena
- Touch joystick movement
- Hold FIRE to shoot
- Goblin waves with increasing difficulty
- XP, levels and gold
- Health and game-over screen
- Procedural rendering: no external assets required
- Android APK built automatically with GitHub Actions

## Build
Open the Actions tab and run **Build Debug APK**, or push to main. The APK is uploaded as a workflow artifact.

This is an original prototype. It does not include assets or source code from other games.
